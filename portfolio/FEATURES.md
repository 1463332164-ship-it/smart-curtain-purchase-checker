# 功能与界面说明

入口index.html与configuration.html显示同一检查器，about.html解释范围。窄屏时输入与结果上下排列，宽屏分列。界面包含预置任务、8个条件输入、检查与清空按钮、结果卡及三点买前说明。

| 输入/输出 | 作用 |
|---|---|
| 型号、结构、杆径、帘头、开合 | 保留适配前提，未知可留待核 |
| 功能目标、品牌Hub、Apple控制器 | 将桥接和平台依赖分开 |
| 结果卡 | 状态、规则编号、事实编号、依据链接与日期 |
| 输入变化 | 隐藏旧结果，显示自定义条件，要求重新检查 |
| 清空 | 恢复空白与等待检查 |

documented仅表示该项资料条件相符；blocked为明确限制；missing为所查路径缺项；verify为待核；info为配置说明。总体只有blocked或verify，不产生购买许可。产品价格、市场规模、评论采集、AI分类、销量分析及设备控制均不属于当前功能。

键盘支持使用原生链接、选择框、输入和按钮；提供跳到内容入口与可见焦点。截图和具体设备覆盖范围见验收记录，不能从CSS断点推断所有设备均通过。
