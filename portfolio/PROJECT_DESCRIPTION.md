# 可复制项目简介

## 中文

智能窗帘购买障碍与配置初筛器：基于SwitchBot与Aqara官方公开资料，将部分安装条件和生态设备要求转化为可追溯规则。通过三个模拟任务展示“尺寸符合但结构不符”“已有Hub仍缺平台控制器”和“Matter信息不足保留待核”，每项结果附规则编号与来源链接。采用本地静态网页，支持GitHub Pages部署。项目使用AI辅助开发，未开展真人研究或实机验证，不声称销售、转化或退货改善。

## English

Smart Curtain Purchase Readiness Checker is a local-first portfolio prototype that turns selected installation and ecosystem requirements from official SwitchBot and Aqara documentation into traceable checks. Three synthetic tasks demonstrate structural mismatches, missing platform controllers and unresolved Matter configurations. Results include rule identifiers and source links. The static site is prepared for GitHub Pages. Development was AI-assisted; no participant study, hardware validation or commercial impact is claimed.
