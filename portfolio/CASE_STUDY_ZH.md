# 智能窗帘购买障碍与配置初筛器

**定位：硬件商业化作品集原型｜公开资料研究 → 配置规则 → 证据解释**

**问题。** 智能窗帘买前条件散落在产品页、兼容说明和生态帮助中。只看到尺寸符合或“已有Hub”，可能遗漏结构限制与平台依赖。这里的“可能”是研究假设，尚未由消费者测试验证。

**范围。** 美国市场资料；SwitchBot Curtain 3 Rod Type 1与Aqara Curtain Driver E1 Rod Version。完成静态交互工具、三类业务情景、可追溯规则和来源说明，不覆盖完整GTM策略。

**方法。** 把准确型号、安装结构、杆径、帘头、开合和控制目标转为输入；将厂商事实、项目判断和未决项分开。每条输出附规则/事实编号和原始链接，保留版本与资料日期。使用免费内置工具，不依赖LLM在线推荐。

**代表判断。** ①E1的30mm尺寸符合，但伸缩结构被排除；②Curtain 3已有品牌Hub，仍需单独核对Apple平台控制器；③E1当前Matter组合信息不足，不判定任意Hub可用，也不误判为不支持。

**可核实交付。** 本地交互页面、22项规则测试、8项UI逻辑测试、来源审计、数据说明、干净发布目录；浏览器实际覆盖与截图另见验收记录。测试数量不代表用户理解率。

**岗位关联。** GTM：识别买前信息缺口、说明设备依赖，形成待验证的购买障碍假设；产品市场：把规格转为有前提的说明与卖点边界；解决方案：拆解条件、指出缺项、保留追溯路径。未声称客户交付或销售改善。

**贡献与限制。** AI辅助资料整理、实现和技术验收；项目发起者参与需求提出、业务规则理解及资料核对；不声称独立完成全部编码。真人研究0、实机0，无业务收益指标。下一步为真实信息理解探索与具体安装条件补核；用户反馈与海外GTM策略仍属扩展计划。
